# Nexus Media

Nexus Media is a fork of [Nuvio TV](https://github.com/NuvioMedia/NuvioTV).

## Install

Enter **6234336** in Downloader on Android TV or Google TV, or [download the current Stable APK](https://github.com/Wizard-Nexus/Nexus-Media/releases/latest/download/Nexus-Media.apk).

## Updates

Stable is selected by default. Choose **Settings → About → Update channel → Beta** to receive Beta builds in the same app. [View releases](https://github.com/Wizard-Nexus/Nexus-Media/releases)
